Lightbox metadata — visual mockups

Static previews of directions A–F from lightbox-metadata-design.md. Phone width ≈ 392px. Not production code—layout and weight only.

The in-app lightbox metadata is a flat list (no card, no rounded row tiles): one stack with top and bottom hairlines plus dividers between rows. Film, camera, lab/scanner, then optional push/pull and lens/ISO. Rows use a subtle full-width strip hover; film thumb has no border or fill.
